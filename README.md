# AI-Powered College FAQ Chatbot

## Project Description
An AI-powered college FAQ chatbot built using Streamlit and Ollama. It allows users to ask questions and receive AI-generated responses.

## Technologies Used
- Python
- Streamlit
- Ollama
- Llama 3.2

## How to Run
1. Activate the virtual environment.
2. Install the required packages.
3. Run the application using Streamlit.
